# Stock Waves

Stock Waves is a modern, real-time stock trading and market analysis platform designed to empower investors with the tools and insights needed to make informed decisions.

## Features

- **Real-Time Market Data**: Stay updated with the latest stock prices and market trends.
- **Company Profiles**: Access detailed information about listed companies, including performance metrics and sector analysis.
- **Investment Insights**: Discover new opportunities and gain deep insights into market dynamics.
- **Portfolio Management**: Tools to track and manage your investments effectively.
- **Responsive Design**: A sleek and modern interface built for both desktop and mobile experiences.

## Tech Stack

- **Frontend**:
  - **HTML5**: Semantic and accessible markup.
  - **CSS3**: Vanilla CSS with modern features like Flexbox, Grid, and Glassmorphism for a premium look.
  - **JavaScript (ES Modules)**: Modular and maintainable application logic without heavy framework overhead.
- **Backend API**:
  - Interaction with a local backend server for data retrieval and user management.

## Project Structure

- `api/`: JavaScript modules for interacting with the backend API.
- `assets/`: Global styles, images, and fonts.
- `components/`: Reusable UI components like headers, footers, and sections.
- `pages/`: Individual application pages (Home, Login, Register, Profile, etc.).

## Getting Started

1. Clone the repository.
2. Ensure you have a local backend server running (default expects `http://localhost:5000`).
3. Open `pages/home/home.html` in a web browser or use a local development server like VS Code's Live Server.
